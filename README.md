# 실험 보고서 형식 검사기

실험 보고서를 넣으면 **제출 전에 형식 오류를 자동으로 찾아 주는** 웹앱입니다.
2026 전곽 SW 경시대회 출품작 (교육활동 개선 분야)

## 해결하려는 문제

실험 보고서는 내용보다 형식에서 감점되는 경우가 많습니다. 항목 누락, 단위 표기(ml, sec), 그림·표 번호 오류, 문체 혼용 같은 것들입니다.
이런 오류는 스스로 찾기 어렵고, 선생님은 같은 지적을 학생마다 반복하게 됩니다.

## 주요 기능

| 검사 | 잡아내는 것 |
| --- | --- |
| 항목 구성 | 필수 항목 누락, 빈 항목, 순서 어긋남, 중복 |
| 단위 표기 | ml→mL, sec→s, Kg→kg, deg→°, cc→mL, 숫자-단위 띄어쓰기 |
| 그림·표 번호 | 번호 건너뜀·중복, 없는 번호 언급, 본문에서 언급 안 한 그림·표 |
| 문체 | 1인칭(나는, 우리는), 구어체(너무, 진짜), 합니다체/하였다체 혼용, 결과의 미래형 |
| 내용 | 결과에 측정값 없음, 고찰에 오차 분석 없음, 결론과 목적 불일치 |
| 참고문헌 | 연도·URL 누락, 웹 자료 접속일 누락 |

- 한글(.hwpx), 워드(.docx), 텍스트(.txt) 파일을 그대로 열 수 있습니다.
- 입력하는 즉시 다시 검사하고, 문제를 누르면 해당 줄로 이동합니다.
- 선생님 양식에 맞게 필수 항목과 검사 규칙을 켜고 끌 수 있습니다.
- 수정 전후 결과를 기록하고 CSV로 내려받아 효과를 비교할 수 있습니다.
- 보고서는 서버로 보내지 않고 브라우저 안에서만 검사합니다.

## 실행 방법

### 1. 바로 쓰기
배포 주소: https://jkpark-jshs.github.io/report-checker/

### 2. 내 컴퓨터에서 실행
1. 이 저장소를 내려받습니다. (Code → Download ZIP 후 압축 풀기)
2. `index.html`을 크롬이나 엣지로 엽니다. 설치할 것은 없습니다.
3. 인터넷이 연결되어 있어야 합니다. (.hwpx/.docx를 여는 JSZip을 CDN에서 불러옴)

### 3. 테스트 실행 (Node.js 필요)
```
node tests/checker.test.js
```
검사 규칙 11개가 의도대로 동작하는지 확인합니다.

## 사용법
1. **파일 열기**로 보고서(.hwpx/.docx/.txt)를 열거나 글을 붙여 넣습니다.
2. 오른쪽에 점수와 문제 목록이 나옵니다. 문제를 누르면 그 줄로 이동합니다.
3. 왼쪽에서 바로 고치면 자동으로 다시 검사됩니다.
4. **이 결과 기록**을 눌러 수정 전후 오류 수를 남깁니다.
5. 옛 한글 형식(.hwp)은 한글에서 "다른 이름으로 저장 → .hwpx"로 바꿔서 여세요.

## 폴더 구조

```
index.html          화면 구조
css/style.css       디자인
js/rules.js         검사 규칙 데이터 (항목 이름, 단위 규칙, 감점)
js/checker.js       검사 엔진 (텍스트 → 문제 목록, 점수)
js/fileReader.js    .hwpx/.docx/.txt에서 글자 추출
js/app.js           화면 동작 (입력, 결과 표시, 설정, 기록)
js/samples.js       시연용 예시 보고서 (가상 자료)
tests/              검사 엔진 테스트
```

규칙(`rules.js`)과 엔진(`checker.js`)을 분리해서, 양식이 달라도 `rules.js`만 고치면 됩니다.

## 점수 계산
100점에서 오류 1개당 10점, 주의 1개당 4점, 권장 1개당 1점을 뺍니다. (최저 0점)
